# Vantage

Governed data integration, metrics and dashboards.

Vantage connects sources through an integration engine and exposes governed products through a shared API. Administration and reporting apps consume that API.

Early development. Product repositories are private while the first release is prepared. Capabilities described here are product direction; licensing is pending.

Components: API, integration engine, administration app, reporting app, reusable AWS modules and self-hosted packaging. Operators retain their own deployment configuration and data.
